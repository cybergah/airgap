Model `gpt-oss:20b` on one local GPU. Success is judged by tests the model never sees.
Old and new were run one after the other, 3 rounds, so both saw the same machine state.

- **Old (0.13.1):** no static check, no reasoning kept across tool calls, no test baseline.
- **New (0.14):** all three on (`KOD_AJANI_TEST_IMAJ` set for the pytest image).

The 6-task difference in this full round is not proof on its own (roughly p = 0.1), but it points the same way
as the targeted measurement below, and no part got worse. The cost: work on real projects takes about a quarter longer.

## Targeted: the 6 flakiest tasks × 5, old and new alternating

| Change | Before | After | Reports |
|---|---|---|---|
| Static check alone | 19/30 | 16/30 | `statik0-*`, `statik1-*` |
| Reasoning kept + static check | 19/30 | **29/30** | `dusunce-eski-*`, `dusunce-yeni-*` |

The static check on its own did not help: the model forgot its plan halfway through and repeated searches.
Keeping its reasoning between tool calls fixed that (repeat stops 4 → 0, false "done" claims 6 → 1),
and only then did the two together make the difference.

We planted these bugs ourselves, so the numbers do not predict results on your own code.
